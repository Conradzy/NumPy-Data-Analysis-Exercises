# NumPy Data Analysis Exercises

A compact collection of NumPy exercises progressing from one-dimensional arrays and matrix arithmetic to boolean filtering, descriptive statistics, missing-value imputation, and correlation analysis.

## Workflow

1. Create arrays and compute sums, means, and scalar operations.
2. Perform matrix addition, subtraction, and multiplication.
3. Use slicing and boolean masks.
4. Generate random matrices and compute summary statistics.
5. Impute missing values and analyze a small student-style dataset.

## Data Requirements

- No external dataset is required; arrays are defined directly in the notebook.

Datasets and generated artifacts are not included unless they are embedded directly in the notebook.

## Requirements

- NumPy

Install missing packages in your Jupyter or Google Colab environment before running the notebook.

## Running the Notebook

1. Open [`napinasnumpyproblems.ipynb`](napinasnumpyproblems.ipynb) in Jupyter Notebook or Google Colab.
2. Place any required data files in the path expected by the notebook.
3. Update local or Google Drive paths where needed.
4. Run the cells from top to bottom.

## Outputs

- Array and matrix operation results
- Filtered observations
- Descriptive statistics and correlation matrix
